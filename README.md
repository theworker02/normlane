# normlane

Norm timestamps and lane durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/normlane/

## Install / run

```bash
git clone https://github.com/theworker02/normlane.git
cd normlane
node src/cli.js
node --test
```
